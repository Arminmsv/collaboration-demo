# Collaboration Demo Project

This project is used to practice Git and GitHub collaboration workflows.

## How to contribute
- Open an issue
- Create a branch
- Submit a pull request

## New Feature

This project includes a simple feature description to demonstrate how a new feature is proposed, documented, reviewed, and integrated through GitHub collaboration.

## Development Workflow

1. Open an issue describing the change.
2. Create a branch for the issue.
3. Make the required changes.
4. Open a pull request.
5. Ask for code review.
6. Apply the requested changes.
7. Merge the approved pull request.

Contributions are welcome.
